Install the detector app

Version 181 · September 1, 2026

Purchased access or the private owner code grants unlimited use on the browser where it is unlocked. This GitHub Pages build stores access locally on that device.

iPhone and iPad

Open the detector in Safari. Tap Share, select Add to Home Screen, keep Open as Web App enabled where shown, and tap Add.

Samsung and other Android phones

Open the detector in Samsung Internet or Chrome. Open the browser menu and select Install app or Add to Home screen, then confirm.

Windows, Chromebook, and macOS

Open the detector in Chrome or Edge and select the install icon in the address bar or browser menu. Safari on supported macOS versions can add the site as a web app.

Using another device

Purchasers can restore access using the checkout email. Private-code access can be unlocked again by entering the code on the detector page.

Internet requirement

Text analysis, document extraction, result explanations, local history, corrections, and exports run in the browser. OCR, public URL scanning, and website crawling require an internet connection. Public web pages are retrieved through the configured web-reader service; document text remains local. This GitHub Pages build stores its three-use counter and private-code access on the current browser only.
